# PROJECT 4 – PASSWORD POLICY VALIDATION ENGINE

## About the Project
The Password Policy Validation Engine project is designed to check whether a password follows the required security rules. It validates passwords based on conditions such as minimum length, uppercase letters, lowercase letters, digits, and special characters. It helps users understand whether their password meets the given security requirements.

## Technologies Used
- **Python** – Used to develop the password validation program.
- **Strings** – Used to process and check password characters.
- **Loops** – Used to examine each character in the password.
- **Conditional Statements** – Used to validate password requirements.
- **Built-in Functions** – Used to check character types.

## Main Features
- Accepts a password from the user.
- Checks the minimum password length.
- Verifies the presence of uppercase letters.
- Checks for lowercase letters.
- Verifies the presence of numbers.
- Checks for special characters.
- Displays whether the password is valid or invalid.
- Shows the rules that are not satisfied.

## Algorithm
1. Start the program.
2. Accept a password from the user.
3. Check whether the password meets the minimum length requirement.
4. Check for uppercase letters.
5. Check for lowercase letters.
6. Check for numeric digits.
7. Check for special characters.
8. Validate all password conditions.
9. Display the password validation result.
10. Stop the program.

## Conclusion
This project helps validate passwords based on predefined security rules. It demonstrates Python concepts such as strings, loops, conditional statements, and built-in functions to create a simple password validation system.
